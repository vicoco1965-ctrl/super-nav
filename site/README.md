# ניווט בסופר

אב-טיפוס של אפליקציית ניווט בתוך סופרמרקט (סניף יוחננוף באר שבע): מצלמים או אומרים את רשימת הקניות, ומקבלים מסלול מסודר עם הכוונה קולית בעברית.

האתר כולו בקובץ `index.html`. בתיקייה `vendor/` נמצא מנוע זיהוי הטקסט (Tesseract.js) והנתונים לעברית, כדי שהזיהוי ירוץ על הטלפון עצמו בלי שרת.
